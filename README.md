# ☕ Velvet Coffee

A responsive, single-page website for a modern coffee shop, built with HTML and CSS. It has a warm dark-brown and gold theme and a video hero section.

🔗 **Live Demo:** https://tamerfatma427-svg.github.io/velvet-coffee/

## ✨ Features

- Mobile-first responsive design (mobile, tablet, desktop)
- Sticky navigation bar with smooth scrolling
- Hero section with a background video
- About, Menu, Gallery, and Contact sections
- Hover effects on buttons, menu cards, and gallery images
- Custom color palette using CSS variables

## 📄 Sections

| Section | Description |
|---------|-------------|
| Home | Hero with background video and call-to-action buttons |
| About | Story of the café with an image |
| Menu | Drink and dessert cards with prices |
| Gallery | Photo grid of the café |
| Contact | Contact info and a message form |
| Footer | Quick links and copyright |

## 🛠️ Built With

- HTML5
- CSS3 (Grid, Flexbox, CSS Variables, Media Queries)
- [Google Fonts](https://fonts.google.com): Playfair Display and Poppins
- [Font Awesome](https://fontawesome.com) for icons

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/tamerfatma427-svg/velvet-coffee.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

No installation or build step needed.

## 📱 Responsive Breakpoints

- **Mobile:** default styles
- **Tablet:** 768px and up
- **Desktop:** 1024px and up
